# 毛球 AI 助手开发教程

## 目标

本项目从一个单文件终端 Demo 演进为本机单用户 Web Agent。原版直接把模型字符串交给 `subprocess.run(..., shell=True)`，只处理第一个工具调用，并且工具结果后的二次模型调用被注释，因此需要重新设计安全、会话和 UI 层。

## 启动

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-dev.txt
python agent.py --web
```

Windows PowerShell：

```powershell
.venv\Scripts\Activate.ps1
python agent.py --web --workspace C:\Users\you\project
```

浏览器使用终端打印的 `http://127.0.0.1:8767/?token=...` 地址访问。首次进入页面填写 API Key、Base URL 和模型名称。

## 架构

```text
CLI/Web -> core.Agent -> OpenAI-compatible API
                     -> 工具注册表 -> 文件/命令/Git/网络工具
                                      -> security 路径沙箱和命令策略
```

`maoqiu.core.Agent.run_turn()` 是唯一的 Agent 循环。终端将事件打印出来，Web 将事件编码为 SSE，避免两套逻辑分叉。

## 配置

`maoqiu/config.py` 管理 API、工作目录、确认模式、超时、输出上限、网络工具、会话、日志和 Web 服务。

优先级：

```text
MAOQIU_API_KEY / OPENAI_API_KEY > config.json
```

`to_public_dict()` 不返回 API Key 或 Web token；环境变量提供的密钥不会写回配置文件。

## 安全执行

命令经过 `classify_command()` 分类：

- `allow`：只读命令，例如 `git status`、`pytest`、目录与文件查看；
- `confirm`：写入、删除、安装、网络和未知命令；
- `deny`：格式化磁盘、删除根目录、关机、强制推送、读取凭据等。

规则先检查完整命令，再按管道、分号、`&&` 拆分，避免 `curl ... | sh` 等组合绕过。命令还带有工作目录、超时、退出码、stdout/stderr 和输出截断。

> 这是本机单用户防护层，不是公网多租户沙箱。更高安全需求应将 shell 字符串改为严格白名单 argv。

## 文件沙箱

所有路径通过 `resolve_in_workspace()`：先解析真实路径，再验证其仍在 `workspace` 内。这拦截 `..`、绝对路径和符号链接逃逸。

`.env`、`config.json`、SSH key、证书和常见凭据文件默认禁止访问。文件工具包括目录查看、读写、精确编辑、删除、创建目录、查找和内容搜索。写入、编辑与删除均需确认；精确编辑默认要求旧文本唯一。

## Agent 多工具循环

工具通过 `@register` 自动生成 Function Calling schema。模型可一次返回多个工具调用；每个调用都必须写回匹配的 `tool_call_id`，再请求模型生成最终回复。循环上限为 10 轮，防止死循环。

事件：`tool_call`、`tool_result`、`text`、`error`、`done`。

## 会话与跨平台

会话按 JSON 存在 `.maoqiu/sessions/`，使用临时文件和 `os.replace()` 原子写入。完整历史保留在磁盘，发给模型时按 `max_history_messages` 裁剪，并避免留下孤立 `tool` 消息。

配置层基于 `platform.system()` 注入 Windows PowerShell、macOS zsh 或 Linux bash 提示。路径一律使用 `pathlib.Path`。

## Git 和网络工具

Git 查询以 argv 执行，提供 status、diff、log 和需确认的 commit。提交要求显式文件列表，阻止常见密钥文件，不自动 push。

网络工具只支持 HTTP/HTTPS，拒绝 localhost、私网、链路本地、云元数据地址和重定向，防止 SSRF。设置页可以整体关闭网络工具。

## Web API

`maoqiu/web/app.py` 提供静态页面、健康检查、配置、会话 CRUD、SSE 消息流和导出：

```text
GET  /api/health
GET/PUT /api/config
POST /api/config/test
GET/POST /api/sessions
GET/PATCH/DELETE /api/sessions/{id}
POST /api/sessions/{id}/messages
GET  /api/sessions/{id}/export
```

前端使用 `fetch()` 和 `ReadableStream` 处理 POST SSE，不能使用只支持 GET 的 `EventSource`。模型和工具文本通过 `textContent` 渲染，不直接插入 HTML。

Web 默认监听 `127.0.0.1`，每次启动使用临时 Bearer Token。令牌只会出现在 CLI 启动时打印的本地 URL 中，**不会**由匿名的 `/api/health` 返回，也不会嵌入 HTML；不要分享该 URL，也不要把服务暴露到公网。

### 确认后的重试

副作用工具被确认门拒绝时，历史里会保留工具错误和模型总结，方便用户看清原因。用户点击“确认后重试”时，`SessionStore.rollback_unconfirmed_turn()` 会移除这一整组被拒绝的记录（user、带 tool_calls 的 assistant、tool 错误，以及可选的模型总结），然后重新发起请求。

这一步是必要的：如果把被拒绝的 tool 结果留在上下文里，模型会认为该操作已经处理过，于是直接给出“已完成”的结论，而工具其实从未执行。相关回归测试见 `tests/test_session.py` 和 `tests/test_web.py`。

### 模块命名注意

`maoqiu/web/__init__.py` 只导出 `create_app` 和 `build_default_app`，不要再导出名为 `app` 的实例。`maoqiu.web.app` 已经是子模块名，若在包里绑定同名对象，会遮蔽该模块，导致 `import maoqiu.web.app` 得到 FastAPI 实例而不是模块。同时不要在模块导入时构造应用，否则导入即会读配置、建会话目录并生成令牌。

## 测试

```bash
python -m pytest -q
```

测试使用 Fake OpenAI client 和临时目录，不需要真实 API Key，也不访问网络。覆盖命令策略、路径穿越、敏感文件、超时、配置优先级、密钥脱敏、多工具调用、工具循环上限和 Web 鉴权。

## 新增工具清单

1. 在 `maoqiu/tools/` 新建模块。
2. 使用 `@register` 写名称、描述、JSON Schema 和风险等级。
3. 校验所有参数。
4. 文件路径必须使用 `resolve_in_workspace()`。
5. 副作用操作调用 `ask_confirmation()`。
6. 返回 `ToolResult`，并补成功、失败、越权和超时测试。

不要直接读取密钥、把未截断的网页内容回填模型，或把任意模型输入直接拼接成 shell 命令。

## 生产化限制

当前实现不适合公网多租户。服务端部署还需要 TLS、用户认证、CSRF 防护、用户级工作区隔离、进程或容器沙箱、配额、限流、审计日志和专用密钥管理。
